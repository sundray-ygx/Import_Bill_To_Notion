本文档提供 Import_Bill_To_Notion 项目的快速导航和索引。

## 项目简介

**Import_Bill_To_Notion** 是一个多租户财务账单管理平台，支持从支付宝、微信支付、银联自动导入账单到 Notion，并提供月度、季度、年度财务复盘功能。

**核心特性**:
- 多平台账单自动导入
- 智能分类和数据路由
- 财务复盘报告生成
- 多用户数据隔离
- Web管理界面

## 关键配置项

### 环境变量

| 变量名 | 说明 | 必填 |
|--------|------|------|
| `SECRET_KEY` | JWT密钥 | 多租户模式必填 |
| `DATABASE_URL` | 数据库连接 | 否 |
| `MULTI_TENANT_ENABLED` | 多租户开关 | 否 |
| `NOTION_API_KEY` | Notion密钥 | 单用户模式必填 |
| `NOTION_INCOME_DATABASE_ID` | 收入数据库 | 单用户模式必填 |
| `NOTION_EXPENSE_DATABASE_ID` | 支出数据库 | 单用户模式必填 |
| `REGISTRATION_ENABLED` | 开放注册 | 否 |

### Notion数据库属性

**收支数据库必需属性**:
- Name (title)
- Price (number)
- Date (date)
- Category (select)
- Income/Expense (select)

**复盘数据库属性**（可选）:
- Name (title)
- Period (rich_text)
- Total Income (number)
- Total Expense (number)
- Net Balance (number)
