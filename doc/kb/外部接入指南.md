## 接入方式

### REST API

系统提供完整的 REST API，支持第三方应用集成：

| 基础URL | 说明 |
|----------|------|
| `http://your-server:8000/api` | API基础路径 |

**认证方式**: Bearer Token (JWT)

```bash
curl -X POST http://your-server:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "user", "password": "pass"}'

# 返回
{
  "access_token": "eyJ...",
  "refresh_token": "eyJ...",
  "user": {...}
}
```

### CLI命令行

支持命令行调用，适合脚本集成：

```bash
# 单次导入
python3 main.py --file /path/to/bill.csv --platform alipay

# 定时运行
python3 main.py --schedule
```

## API使用

### 1. 认证流程

#### 注册新用户

```bash
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "username": "external_user",
    "email": "user@example.com",
    "password": "SecurePass123"
  }'
```

#### 获取令牌

```bash
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "external_user",
    "password": "SecurePass123"
  }'
```

### 2. 上传账单

```bash
curl -X POST http://localhost:8000/api/upload \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -F "file=@/path/to/bill.csv" \
  -F "platform=auto" \
  -F "sync_type=immediate"
```

### 3. 查询历史

```bash
curl -X GET "http://localhost:8000/api/bills/history?page=1&page_size=20" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### 4. 生成复盘

```bash
curl -X POST http://localhost:8000/api/review/generate \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "monthly",
    "year": 2024,
    "month": 1
  }'
```

## Webhook集成

### 通知配置

系统支持导入完成后发送通知（需自行实现）：

```python
# 伪代码示例
def notify_webhook(webhook_url, data):
    """导入完成后通知外部系统"""
    import requests

    payload = {
        "event": "import_completed",
        "timestamp": datetime.now().isoformat(),
        "data": data
    }

    requests.post(webhook_url, json=payload)
```

### 支持的事件

| 事件 | 触发时机 | 数据内容 |
|------|----------|----------|
| `import_completed` | 账单导入完成 | total_records, imported, skipped |
| `review_generated` | 复盘生成完成 | period, page_id, summary |
| `error` | 导入失败 | error_message, file_name |

## 部署方式

### Docker部署

创建 `Dockerfile`:

```dockerfile
FROM python:3.10-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["python3", "-m", "web_service.main"]
```

构建并运行：

```bash
docker build -t bill-import .
docker run -d -p 8000:8000 \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/.env:/app/.env \
  --name bill-import \
  bill-import
```

### systemd服务

创建 `/etc/systemd/system/bill-import.service`:

```ini
[Unit]
Description=Bill Import Service
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/Import_Bill_To_Notion
Environment="PATH=/opt/Import_Bill_To_Notion/.venv/bin"
ExecStart=/opt/Import_Bill_To_Notion/.venv/bin/python -m web_service.main
Restart=always

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable bill-import
sudo systemctl start bill-import
```

### Nginx反向代理

配置 `/etc/nginx/sites-available/bill-import`:

```nginx
server {
    listen 80;
    server_name bill.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    client_max_body_size 50M;
}
```

## SDK示例（Python）

```python
from typing import Optional
import requests


class BillImportClient:
    """Import_Bill_To_Notion SDK客户端"""

    def __init__(self, base_url: str = "http://localhost:8000"):
        self.base_url = base_url
        self.access_token: Optional[str] = None
        self.refresh_token: Optional[str] = None

    def login(self, username: str, password: str) -> dict:
        """用户登录"""
        response = requests.post(
            f"{self.base_url}/api/auth/login",
            json={"username": username, "password": password}
        )
        response.raise_for_status()
        data = response.json()
        self.access_token = data["access_token"]
        self.refresh_token = data["refresh_token"]
        return data["user"]

    def _get_headers(self) -> dict:
        """获取请求头"""
        return {"Authorization": f"Bearer {self.access_token}"}

    def upload_bill(
        self,
        file_path: str,
        platform: str = "auto",
        sync_type: str = "immediate"
    ) -> dict:
        """上传账单文件"""
        with open(file_path, "rb") as f:
            files = {"file": f}
            data = {"platform": platform, "sync_type": sync_type}
            response = requests.post(
                f"{self.base_url}/api/upload",
                headers=self._get_headers(),
                files=files,
                data=data
            )
        response.raise_for_status()
        return response.json()

    def get_history(self, page: int = 1, page_size: int = 20) -> dict:
        """获取导入历史"""
        response = requests.get(
            f"{self.base_url}/api/bills/history",
            headers=self._get_headers(),
            params={"page": page, "page_size": page_size}
        )
        response.raise_for_status()
        return response.json()

    def generate_review(
        self,
        review_type: str,
        year: int,
        month: Optional[int] = None,
        quarter: Optional[int] = None
    ) -> dict:
        """生成财务复盘"""
        payload = {"type": review_type, "year": year}
        if month:
            payload["month"] = month
        if quarter:
            payload["quarter"] = quarter

        response = requests.post(
            f"{self.base_url}/api/review/generate",
            headers=self._get_headers(),
            json=payload
        )
        response.raise_for_status()
        return response.json()

    def preview_review(
        self,
        review_type: str,
        year: int,
        month: Optional[int] = None,
        quarter: Optional[int] = None
    ) -> dict:
        """预览复盘数据"""
        params = {"type": review_type, "year": year}
        if month:
            params["month"] = month
        if quarter:
            params["quarter"] = quarter

        response = requests.get(
            f"{self.base_url}/api/review/preview",
            headers=self._get_headers(),
            params=params
        )
        response.raise_for_status()
        return response.json()


# 使用示例
if __name__ == "__main__":
    client = BillImportClient("https://your-server.com")

    # 登录
    user = client.login("username", "password")
    print(f"登录成功: {user['username']}")

    # 上传账单
    result = client.upload_bill("/path/to/alipay.csv", platform="alipay")
    print(f"导入完成: {result['import_result']['imported']} 条记录")

    # 生成月度复盘
    review = client.generate_review("monthly", 2024, 1)
    print(f"复盘已生成: {review['page_url']}")
```
