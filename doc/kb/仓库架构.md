## 架构概览

Import_Bill_To_Notion 是一个多租户财务账单管理平台，支持从支付宝、微信支付、银联自动导入账单到 Notion，并提供财务复盘功能。

```
+-----------------------------------------------------------------------+
|                         用户界面层                                      |
|  Web UI (HTML/CSS/JS) | CLI命令行 | 定时调度器                         |
+-----------------------------------------------------------------------+
                                    |
                                    v
+-----------------------------------------------------------------------+
|                         Web服务层                                       |
|  FastAPI Application | 路由 (routes/) | 静态文件 | 模板引擎           |
+-----------------------------------------------------------------------+
                                    |
                                    v
+-----------------------------------------------------------------------+
|                         业务逻辑层                                       |
|  +-----------+  +------------+  +------------+  +------------------+  |
|  | 认证授权   |  | 账单导入   |  | 复盘服务   |  | 用户管理         |  |
|  | auth.py    |  | importer.py|  | review     |  | users/bills/admin|  |
|  +-----------+  +------------+  +------------+  +------------------+  |
+-----------------------------------------------------------------------+
                                    |
                                    v
+-----------------------------------------------------------------------+
|                         数据访问层                                       |
|  +------------+  +------------+  +------------+  +------------------+  |
|  | Notion API |  | 数据库ORM  |  | 文件服务   |  | 配置管理         |  |
|  | notion_api |  | SQLAlchemy |  | file_service|  | config.py        |  |
|  +------------+  +------------+  +------------+  +------------------+  |
+-----------------------------------------------------------------------+
                                    |
                                    v
+-----------------------------------------------------------------------+
|                         外部服务层                                       |
|  Notion API | SQLite/PostgreSQL | 本地文件系统                         |
+-----------------------------------------------------------------------+
```

## 分层架构

### 1. 表示层 (Presentation Layer)

**位置**: `web_service/templates/`, `web_service/static/`, `src/main.py`

**职责**:
- Web用户界面渲染
- CLI命令行交互
- 用户输入验证和展示

**主要组件**:
- Jinja2模板引擎
- 静态资源（CSS/JS）
- CLI参数解析

### 2. 应用服务层 (Application Service Layer)

**位置**: `web_service/main.py`, `web_service/routes/`

**职责**:
- HTTP请求/响应处理
- 路由管理
- 会话管理
- API端点定义

**主要组件**:
- FastAPI应用实例
- 路由模块（auth, users, bills, review, admin, upload）
- 中间件（CORS, 认证）

### 3. 业务逻辑层 (Business Logic Layer)

**位置**: `src/`, `parsers/`

**职责**:
- 核心业务规则实现
- 数据转换和处理
- 外部服务集成

**主要组件**:
- `importer.py` - 账单导入编排
- `auth.py` - 认证授权逻辑
- `review_service.py` - 财务复盘
- `parsers/` - 各平台账单解析器

### 4. 数据访问层 (Data Access Layer)

**位置**: `src/notion_api.py`, `src/services/database.py`

**职责**:
- 外部API交互
- 数据库CRUD操作
- 文件系统操作
- 缓存管理

**主要组件**:
- `NotionClient` - Notion API封装
- SQLAlchemy ORM - 数据库操作
- `FileService` - 文件操作

## 运行模式

系统支持三种运行模式：

### 1. Web服务模式

**入口**: `web_service/main.py`

**启动方式**:
```bash
python3 -m web_service.main
```

**特性**:
- FastAPI + Uvicorn服务器
- 支持多用户认证
- RESTful API
- Web界面管理

### 2. 调度器模式

**入口**: `src/main.py --schedule`

**启动方式**:
```bash
python3 main.py --schedule
```

**特性**:
- APScheduler后台调度
- 定时自动导入账单
- 适合无人值守运行

### 3. CLI单次导入模式

**入口**: `src/main.py --file`

**使用方式**:
```bash
python3 main.py --file <bill-file-path> [--platform <platform>]
```

**特性**:
- 命令行单次导入
- 支持平台指定
- 适合脚本集成

## 数据流图

### 账单导入流程

```
用户上传文件
      |
      v
文件验证 (file_service)
      |
      v
平台检测 (parsers/__init__.py)
      |
      v
选择解析器 (alipay/wechat/unionpay)
      |
      v
解析CSV/Excel (parser.parse())
      |
      v
转换为Notion格式 (parser.to_notion_format())
      |
      v
过滤"不计收支"记录
      |
      v
批量导入Notion (NotionClient.batch_import)
      |
      v
记录导入历史 (ImportHistory)
```

### 用户认证流程

```
用户登录请求
      |
      v
验证输入 (schemas.py)
      |
      v
查询用户 (database.py)
      |
      v
验证密码 (auth.py)
      |
      v
生成JWT令牌 (auth.py)
      |
      v
创建会话 (UserSession)
      |
      v
返回令牌
```

## 扩展性设计

### 1. 新增平台解析器

在 `parsers/` 目录下：
1. 继承 `BaseBillParser`
2. 实现 `parse()` 和 `_convert_to_notion()` 方法
3. 在 `parsers/__init__.py` 中注册

### 2. 新增API路由

在 `web_service/routes/` 目录下：
1. 创建新的路由模块
2. 使用 `APIRouter()` 定义端点
3. 在 `web_service/main.py` 中注册路由

### 3. 新增数据库模型

在 `src/models.py` 中：
1. 继承 `Base` 类
2. 定义表结构和字段
3. 在 `src/services/database.py` 的 `init_db()` 中导入
