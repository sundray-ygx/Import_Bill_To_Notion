## 用户注册

### 流程概述

```
填写表单 -> 验证输入 -> 创建用户 -> 生成令牌 -> 返回结果
```

### 详细步骤

#### 1. 表单验证

**验证规则**:
- 用户名: 3-50字符，字母数字下划线
- 邮箱: 有效邮箱格式
- 密码: 至少8位，包含大小写字母和数字

**代码**: `src/schemas.py:37-44`

#### 2. 检查用户是否存在

```sql
SELECT * FROM users WHERE username = ? OR email = ?
```

**代码**: `web_service/routes/auth.py:60-69`

#### 3. 创建用户记录

- 密码使用 bcrypt 哈希（12轮）
- 生成用户ID
- 设置默认值（is_active=True, is_superuser=False）

**代码**: `src/auth.py:59-78`

#### 4. 生成令牌

- 访问令牌: 有效期15分钟
- 刷新令牌: 有效期7天
- 包含用户ID和用户名

**代码**: `src/auth.py:124-183`

#### 5. 创建会话

- 记录IP地址和用户代理
- 设置过期时间

**代码**: `web_service/routes/auth.py:82-95`

### 状态转换

```
未注册 -> [注册成功] -> 已激活 -> [首次登录] -> 正常使用
         |
         +--->[注册失败]--> 返回错误信息
```

## 用户登录

### 流程概述

```
提交凭证 -> 检查账户 -> 验证密码 -> 处理失败 -> 生成令牌 -> 返回结果
```

### 详细步骤

#### 1. 账户状态检查

检查以下状态：
- 账户是否存在
- 账户是否激活（`is_active`）
- 账户是否被锁定（`locked_until`）

**代码**: `src/auth.py:379-398`

#### 2. 密码验证

```python
# bcrypt验证
verify_password(plain_password, hashed_password)
```

**代码**: `src/auth.py:37-56`

#### 3. 失败处理

失败次数处理逻辑：
```
第1次失败: 记录次数 = 1
第2次失败: 记录次数 = 2
...
第5次失败: 锁定账户30分钟
```

**代码**: `src/auth.py:401-422`

#### 4. 成功处理

- 清除失败次数
- 更新最后登录时间
- 生成令牌
- 创建会话

#### 5. 安全措施

| 安全措施 | 说明 |
|----------|------|
| 密码哈希 | bcrypt，12轮计算 |
| 登录限制 | 5次失败锁定30分钟 |
| 会话超时 | 可配置，默认15分钟 |
| 令牌刷新 | 支持7天有效期刷新令牌 |

## 账单导入

### 流程概述

```
上传文件 -> 格式检测 -> 解析数据 -> 转换格式 -> 过滤记录 -> 批量导入 -> 记录历史
```

### 详细步骤

#### 1. 文件上传验证

```python
# 验证项
- 文件大小 <= MAX_UPLOAD_SIZE (50MB)
- 文件扩展名 in ALLOWED_FILE_EXTENSIONS
- 文件内容可读取
```

**代码**: `web_service/routes/upload.py:42-78`

#### 2. 平台检测

```python
# 检测关键词
- 微信: "微信支付账单明细", "微信昵称", "微信号"
- 支付宝: "支付宝支付科技有限公司", "支付宝账户"
- 银联: "银联", "unionpay", "中国银联"
```

**代码**: `parsers/__init__.py:65-76`

#### 3. 文件解析

**CSV/TXT文件**:
1. 查找表头行（关键词检测）
2. 尝试多种编码（GBK, UTF-8, GB2312）
3. 读取数据到 pandas DataFrame

**Excel文件**:
1. 使用 openpyxl (xlsx) 或 xlrd (xls)
2. 查找表头行
3. 读取数据

**代码**: `parsers/base_parser.py:37-108`

#### 4. 列映射

将原始列名映射到标准列名：

```python
# 支付宝示例
COLUMN_MAP = {
    '交易时间': 'transaction_time',
    '交易分类': 'transaction_type',
    '交易对方': 'counterparty',
    '商品说明': 'item_name',
    '金额': 'amount',
    '收/支': 'income_expense',
    ...
}
```

**代码**: `parsers/alipay_parser.py:14-27`

#### 5. 数据清洗

- 金额字段: 去除货币符号、千位分隔符，转为绝对值
- 日期字段: 标准化为 ISO 格式
- 空值处理: 填充默认值或跳过

**代码**: `parsers/base_parser.py:197-218`

#### 6. 转换为 Notion 格式

```python
{
    'Name': {'title': [{'text': {'content': '商品名称'}}]},
    'Price': {'number': 100.50},
    'Date': {'date': {'start': '2024-01-15T10:30:00', 'time_zone': 'Asia/Shanghai'}},
    'Category': {'select': {'name': '餐饮'}},
    'Income/Expense': {'select': {'name': '支出'}},
    ...
}
```

**代码**: `parsers/alipay_parser.py:98-112`

#### 7. 过滤记录

```python
# 跳过 "不计收支" 记录
if record['income_expense'] == '不计收支':
    continue
```

**代码**: `parsers/base_parser.py:232-234`

#### 8. 批量导入

- 默认每批10条记录
- 根据收支类型路由到不同数据库
- 记录成功/失败/跳过数量

**代码**: `src/notion_api.py:210-238`

#### 9. 创建历史记录

```python
import_history = ImportHistory(
    user_id=user_id,
    upload_id=upload.id,
    total_records=len(records),
    imported_records=success_count,
    skipped_records=skip_count,
    failed_records=fail_count,
    status='success' if fail_count == 0 else 'partial'

```

**代码**: 在各路由中处理

## 财务复盘

### 流程概述

```
选择周期 -> 查询交易 -> 计算汇总 -> 分类聚合 -> 生成报告 -> 创建页面
```

### 详细步骤

#### 1. 周期计算

```python
# 月度复盘
start_date = date(year, month, 1)
end_date = start_date + relativedelta(months=1, days=-1)

# 季度复盘
start_month = (quarter - 1) * 3 + 1
start_date = date(year, start_month, 1)
end_date = start_date + relativedelta(months=3, days=-1)

# 年度复盘
start_date = date(year, 1, 1)
end_date = date(year, 12, 31)
```

**代码**: `src/review_service.py:1401-1605`

#### 2. 数据查询

**日期范围 <= 90天**:
```python
# 直接查询
results = client.databases.query(
    database_id=income_db,
    filter={"property": "Date", "date": {...}}
)
```

**日期范围 > 90天**:
```python
# 分批查询（每批30天）
for batch_start in range(start, end, 30_days):
    query_database(batch_start, min(batch_start + 30_days, end))
```

**代码**: `src/review_service.py:46-160`

#### 3. 汇总计算

```python
summary = {
    'total_income': sum(收入记录金额),
    'total_expense': sum(支出记录金额),
    'net_balance': total_income - total_expense,
    'transaction_count': len(所有记录)
}
```

**代码**: `src/review_service.py:376-408`

#### 4. 分类聚合

```python
categories = {}
for 交易 in 记录列表:
    category = 交易.分类
    if category not in categories:
        categories[category] = {'income': 0, 'expense': 0}
    categories[category][交易.收支类型] += 交易.金额
```

**代码**: `src/review_service.py:339-374`

#### 5. TOP分类计算

```python
# 支出TOP5
expense_sorted = sorted(
    [(cat, amounts['expense']) for cat, amounts in categories.items() if amounts['expense'] > 0],
    key=lambda x: x[1],
    reverse=True
)[:5]
```

#### 6. 报告生成

**有模板**:
1. 读取模板页面
2. 替换占位符
3. 创建新页面

**无模板**:
1. 创建基础页面
2. 添加内容块

**代码**: `src/review_service.py:456-649`
