## 业务概述

Import_Bill_To_Notion 是一个**多租户财务账单管理平台**，核心价值是：

1. **自动化导入**: 从支付宝、微信支付、银联自动导入账单到 Notion
2. **智能分类**: 根据收/支类型自动路由到不同数据库
3. **财务复盘**: 生成月度、季度、年度财务分析报告
4. **数据安全**: 多用户数据隔离，企业级安全标准

## 核心概念

### 多租户模式

系统支持两种运行模式：

#### 单用户模式
- 使用全局配置的 Notion API 密钥
- 适合个人使用
- 配置简单，无需数据库

#### 多租户模式
- 每个用户独立的 Notion 配置
- 数据完全隔离
- 支持团队协作
- 需要 SQLite 数据库

**配置**: 通过 `MULTI_TENANT_ENABLED` 环境变量控制

**相关代码**: `src/config.py:67-93`

---

### 支付平台

系统支持三大支付平台：

| 平台 | 标识 | 账单格式 | 解析器 |
|------|------|----------|--------|
| 支付宝 | `alipay` | CSV/TXT/XLS/XLSX | `AlipayParser` |
| 微信支付 | `wechat` | CSV/TXT/XLS/XLSX | `WeChatParser` |
| 银联 | `unionpay` | CSV/TXT/XLS/XLSX | `UnionPayParser` |

**平台检测**:
- 自动读取文件前20行
- 检查平台特征关键词
- 支持手动指定平台

**相关代码**: `parsers/__init__.py:15-80`

---

### 收支类型

每笔交易都有收支类型属性：

| 类型 | 说明 | 数据库路由 |
|------|------|-----------|
| 收入 | 资金流入 | 收入数据库 |
| 支出 | 资金流出 | 支出数据库 |
| 不计收支 | 内部转账、退款等 | 过滤不导入 |

**相关代码**: `parsers/base_parser.py:226-238`

## 用户管理

### 用户生命周期

```
注册 -> 激活 -> 配置Notion -> 使用账单导入 -> (可选)配置复盘
```

### 用户状态

| 状态 | 说明 | 允许操作 |
|------|------|----------|
| 激活 (`is_active=True`) | 正常状态 | 所有功能 |
| 未激活 (`is_active=False`) | 已禁用 | 无操作权限 |
| 锁定 (`locked_until`有值) | 登录锁定 | 等待解锁 |
| 需要改密 (`require_password_change=True`) | 首次登录或强制改密 | 仅改密 |

### 用户角色

| 角色 | 权限 |
|------|------|
| 普通用户 | 个人数据管理、账单导入、复盘生成 |
| 超级用户 (`is_superuser=True`) | 所有权限 + 用户管理、系统设置 |

### 会话管理

- 访问令牌有效期: 15分钟（可配置）
- 刷新令牌有效期: 7天
- 会话超时: 每用户可配置（5-1440分钟）
- 支持多设备登录（每个会话独立记录）

**相关代码**: `src/models.py:12-46`, `src/auth.py:253-311`

## 账单管理

### 导入流程

```
上传文件 -> 格式检测 -> 解析数据 -> 格式转换 -> 过滤记录 -> 批量导入 -> 记录历史
```

### 上传方式

| 方式 | 说明 |
|------|------|
| 立即导入 | 上传后立即解析并导入到 Notion |
| 定时导入 | 上传后等待调度器执行（未完全实现） |

### 平台检测策略

1. 读取文件前20行
2. 尝试多种编码（GBK、UTF-8、GB2312）
3. 检查平台特征关键词
4. Excel文件需要使用专用引擎读取

### 数据过滤

自动过滤以下记录：
- `income_expense == '不计收支'` 的记录
- 空记录或字段缺失的记录

### 数据转换

解析后的数据转换为 Notion 格式：

| 原始字段 | Notion属性 | 转换规则 |
|----------|------------|----------|
| 交易时间 | Date | ISO格式 + Asia/Shanghai时区 |
| 商品说明/交易类型 | Name | 标题类型 |
| 金额 | Price | 数值类型（取绝对值） |
| 交易分类 | Category | 选择类型 |
| 交易对方 | Counterparty | 富文本 |
| 收/支 | Income/Expense | 选择类型 |
| 支付方式 | Payment Method | 选择类型 |
| 交易平台 | From | 选择类型 |

**相关代码**: `src/importer.py:12-105`, `parsers/base_parser.py:226-244`

## 财务复盘

### 复盘类型

| 类型 | 周期 | 数据库 |
|------|------|--------|
| 月度复盘 | 每月 | `NOTION_MONTHLY_REVIEW_DB` |
| 季度复盘 | 每季度 | `NOTION_QUARTERLY_REVIEW_DB` |
| 年度复盘 | 每年 | `NOTION_YEARLY_REVIEW_DB` |

### 复盘数据

从收支数据库聚合计算：

1. **汇总数据**
   - 总收入 (`total_income`)
   - 总支出 (`total_expense`)
   - 净余额 (`net_balance`)
   - 交易笔数 (`transaction_count`)

2. **分类统计**
   - 按分类聚合收入
   - 按分类聚合支出
   - 计算各分类占比

3. **TOP分析**
   - 收入TOP5分类
   - 支出TOP5分类

### 复盘生成

```
选择周期 -> 查询交易数据 -> 计算汇总 -> 分类聚合 -> 填充模板 -> 创建页面
```

### 模板支持

- 支持使用 Notion 页面作为模板
- 模板中的占位符会被实际数据替换
- 无模板时使用默认格式

**相关代码**: `src/review_service.py:1401-1605`

## 系统配置

### 全局配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `REGISTRATION_ENABLED` | 是否开放注册 | `true` |
| `MAX_UPLOAD_SIZE` | 最大上传文件大小 | 50MB |
| `ALLOWED_FILE_EXTENSIONS` | 允许的文件扩展名 | .csv,.txt,.xls,.xlsx |
| `SESSION_TIMEOUT_MINUTES` | 默认会话超时 | 15分钟 |
| `MAX_LOGIN_ATTEMPTS` | 最大登录尝试次数 | 5次 |
| `LOCKOUT_DURATION_MINUTES` | 锁定时长 | 30分钟 |

### 用户配置

每个用户可以配置：

1. **Notion配置**
   - API密钥
   - 收入数据库ID
   - 支出数据库ID
   - 配置名称

2. **复盘配置**
   - 月度复盘数据库ID
   - 季度复盘数据库ID
   - 年度复盘数据库ID
   - 各类型模板ID

3. **个人设置**
   - 会话超时时间
   - 密码（可修改）

**相关代码**: `src/models.py:71-103`

## 数据隔离

### 多租户隔离

- 所有用户数据通过 `user_id` 关联
- 用户只能访问自己的数据
- 超级用户可以管理所有用户

### 级联删除

- 删除用户时，级联删除：
  - 用户会话 (`UserSession`)
  - Notion配置 (`UserNotionConfig`)
  - 上传记录 (`UserUpload`)
  - 导入历史 (`ImportHistory`)
  - 审计日志 (`AuditLog`)

## 业务规则

### 密码策略

- 最少8位字符
- 至少一个大写字母
- 至少一个小写字母
- 至少一个数字
- 使用 bcrypt 哈希存储

### 登录安全

- 5次失败后锁定账户30分钟
- 记录每次登录尝试
- 支持会话超时自动注销

### 文件上传

- 支持的格式: CSV, TXT, XLS, XLSX
- 最大文件大小: 50MB（可配置）
- 文件保存在用户专属目录

### 导入限制

- 单次最多导入: 无硬限制
- 批量大小: 10条/批
- 超时时间: 180秒（Notion API）
