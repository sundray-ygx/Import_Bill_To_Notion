## 数据库模型

数据库模型定义在 `src/models.py` 中，使用 SQLAlchemy ORM。

### User - 用户表

**表名**: `users`

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | Integer | PRIMARY KEY, AUTO_INCREMENT | 用户ID |
| username | String(50) | UNIQUE, NOT NULL, INDEX | 用户名 |
| email | String(100) | UNIQUE, NOT NULL, INDEX | 电子邮箱 |
| password_hash | String(255) | NOT NULL | 密码哈希 |
| is_superuser | Boolean | DEFAULT: False, INDEX | 是否超级用户 |
| is_active | Boolean | DEFAULT: True, INDEX | 是否激活 |
| require_password_change | Boolean | DEFAULT: False | 是否需要修改密码 |
| created_at | DateTime | server_default=func.now() | 创建时间 |
| updated_at | DateTime | server_default=func.now(), onupdate=func.now() | 更新时间 |
| last_login | DateTime | - | 最后登录时间 |
| login_attempts | Integer | DEFAULT: 0 | 登录尝试次数 |
| locked_until | DateTime | - | 锁定到期时间 |
| session_timeout_minutes | Integer | DEFAULT: 15 | 会话超时分钟数 |

**关系**:
- sessions -> UserSession (一对多)
- notion_config -> UserNotionConfig (一对一)
- uploads -> UserUpload (一对多)
- import_history -> ImportHistory (一对多)
- audit_logs -> AuditLog (一对多)

### UserSession - 用户会话表

**表名**: `user_sessions`

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | Integer | PRIMARY KEY, AUTO_INCREMENT | 会话ID |
| user_id | Integer | FOREIGN KEY -> users.id, NOT NULL, INDEX | 用户ID |
| token | String(255) | UNIQUE, NOT NULL, INDEX | 访问令牌 |
| refresh_token | String(255) | UNIQUE, INDEX | 刷新令牌 |
| expires_at | DateTime | NOT NULL, INDEX | 过期时间 |
| created_at | DateTime | server_default=func.now() | 创建时间 |
| ip_address | String(45) | - | IP地址 |
| user_agent | Text | - | 用户代理 |
| is_revoked | Boolean | DEFAULT: False | 是否已撤销 |

### UserNotionConfig - 用户Notion配置表

**表名**: `user_notion_configs`

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | Integer | PRIMARY KEY, AUTO_INCREMENT | 配置ID |
| user_id | Integer | FOREIGN KEY -> users.id, UNIQUE, NOT NULL, INDEX | 用户ID |
| notion_api_key | String(255) | NOT NULL | Notion API密钥 |
| notion_income_database_id | String(100) | NOT NULL | 收入数据库ID |
| notion_expense_database_id | String(100) | NOT NULL | 支出数据库ID |
| config_name | String(100) | DEFAULT: "默认配置" | 配置名称 |
| is_verified | Boolean | DEFAULT: False | 是否已验证 |
| last_verified_at | DateTime | - | 最后验证时间 |
| notion_monthly_review_db | String(100) | - | 月度复盘数据库ID |
| notion_quarterly_review_db | String(100) | - | 季度复盘数据库ID |
| notion_yearly_review_db | String(100) | - | 年度复盘数据库ID |
| notion_monthly_template_id | String(100) | - | 月度复盘模板ID |
| notion_quarterly_template_id | String(100) | - | 季度复盘模板ID |
| notion_yearly_template_id | String(100) | - | 年度复盘模板ID |
| created_at | DateTime | server_default=func.now() | 创建时间 |
| updated_at | DateTime | server_default=func.now(), onupdate=func.now() | 更新时间 |

### UserUpload - 用户上传记录表

**表名**: `user_uploads`

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | Integer | PRIMARY KEY, AUTO_INCREMENT | 上传ID |
| user_id | Integer | FOREIGN KEY -> users.id, NOT NULL, INDEX | 用户ID |
| file_name | String(255) | - | 保存后的文件名 |
| original_file_name | String(255) | NOT NULL | 原始文件名 |
| file_path | String(500) | - | 完整文件路径 |
| file_size | Integer | - | 文件大小（字节） |
| platform | String(20) | NOT NULL | 支付平台 |
| upload_type | String(20) | DEFAULT: "immediate" | 上传类型 |
| status | String(20) | DEFAULT: "pending", INDEX | 状态 |
| created_at | DateTime | server_default=func.now(), INDEX | 创建时间 |

### ImportHistory - 导入历史表

**表名**: `import_history`

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | Integer | PRIMARY KEY, AUTO_INCREMENT | 历史ID |
| user_id | Integer | FOREIGN KEY -> users.id, NOT NULL, INDEX | 用户ID |
| upload_id | Integer | FOREIGN KEY -> user_uploads.id, INDEX | 上传ID |
| total_records | Integer | NOT NULL | 总记录数 |
| imported_records | Integer | DEFAULT: 0 | 已导入数 |
| skipped_records | Integer | DEFAULT: 0 | 跳过数 |
| failed_records | Integer | DEFAULT: 0 | 失败数 |
| status | String(20) | NOT NULL | 状态 |
| error_message | Text | - | 错误消息 |
| started_at | DateTime | server_default=func.now(), INDEX | 开始时间 |
| completed_at | DateTime | - | 完成时间 |
| duration_seconds | Integer | - | 耗时秒数 |

### SystemSettings - 系统设置表

**表名**: `system_settings`

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | Integer | PRIMARY KEY, AUTO_INCREMENT | 设置ID |
| setting_key | String(100) | UNIQUE, NOT NULL, INDEX | 设置键 |
| setting_value | Text | - | 设置值 |
| description | Text | - | 描述 |
| updated_by | Integer | FOREIGN KEY -> users.id | 更新者 |
| updated_at | DateTime | server_default=func.now(), onupdate=func.now() | 更新时间 |

### AuditLog - 审计日志表

**表名**: `audit_logs`

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | Integer | PRIMARY KEY, AUTO_INCREMENT | 日志ID |
| user_id | Integer | FOREIGN KEY -> users.id, INDEX | 用户ID |
| action | String(100) | NOT NULL, INDEX | 操作类型 |
| resource_type | String(50) | INDEX | 资源类型 |
| resource_id | Integer | INDEX | 资源ID |
| ip_address | String(45) | - | IP地址 |
| user_agent | Text | - | 用户代理 |
| details | Text | - | 详细信息（JSON） |
| created_at | DateTime | server_default=func.now(), INDEX | 创建时间 |

## Pydantic Schemas

Pydantic schemas 定义在 `src/schemas.py` 中，用于 API 请求/响应验证。

### 用户相关 Schema

#### UserBase
```python
{
    "username": str,  # 3-50字符
    "email": EmailStr
}
```

#### UserCreate
```python
{
    "username": str,
    "email": EmailStr,
    "password": str  # 8-100字符，必须包含大小写字母和数字
}
```

#### UserResponse
```python
{
    "id": int,
    "username": str,
    "email": EmailStr,
    "is_superuser": bool,
    "is_active": bool,
    "require_password_change": bool,
    "created_at": datetime,
    "last_login": Optional[datetime]
}
```

### 认证相关 Schema

#### TokenResponse
```python
{
    "access_token": str,
    "refresh_token": str,
    "token_type": str,  # "bearer"
    "expires_in": int,
    "user": UserResponse
}
```

#### PasswordChangeRequest
```python
{
    "current_password": str,
    "new_password": str  # 密码强度验证
}
```

### Notion配置相关 Schema

#### NotionConfigCreate
```python
{
    "notion_api_key": str,  # 最少10字符
    "notion_income_database_id": str,
    "notion_expense_database_id": str,
    "config_name": str  # 默认"默认配置"
}
```

#### NotionVerifyStepResponse
```python
{
    "step": str,  # "api_key", "income_db", "expense_db"
    "status": str,  # "pending", "in_progress", "success", "error"
    "message": str,
    "details": Optional[dict],
    "error": Optional[str]
}
```

#### NotionVerifyProgressResponse
```python
{
    "current_step": int,  # 1-3
    "total_steps": 3,
    "steps": List[NotionVerifyStepResponse],
    "is_complete": bool,
    "all_success": bool
}
```

### 文件上传相关 Schema

#### UploadRequest
```python
{
    "platform": Optional[str],  # "alipay", "wechat", "unionpay", "auto"
    "sync_type": str  # "immediate" 或 "scheduled"
}
```

#### UploadResponse
```python
{
    "success": bool,
    "message": str,
    "upload_id": int,
    "file": FileUploadResponse,
    "import_result": Optional[dict]
}
```

#### FileUploadResponse
```python
{
    "id": int,
    "file_name": str,
    "original_file_name": str,
    "file_size": int,
    "platform": str,
    "upload_type": str,
    "status": str,
    "created_at": datetime
}
```

### 导入历史相关 Schema

#### ImportHistoryResponse
```python
{
    "id": int,
```

## Notion 数据库格式

### 收入/支出数据库格式

账单记录必须包含以下属性：

| 属性名 | Notion类型 | 说明 | 示例值 |
|--------|------------|------|--------|
| Name | title | 账单记录名称 | "星巴克咖啡" |
| Price | number | 金额 | 35.00 |
| Date | date | 交易日期 | "2024-01-15" |
| Category | select | 交易分类 | "餐饮" |
| Counterparty | rich_text | 交易对方 | "星巴克" |
| Remarks | rich_text | 备注 | "拿铁" |
| Income/Expense | select | 收支类型 | "收入" 或 "支出" |
| Merchant Tracking Number | rich_text | 商家订单号 | "2024011500123" |
| Transaction Number | rich_text | 交易单号 | "20240115234123..." |
| Payment Method | select | 支付方式 | "余额" |
| From | select | 支付平台 | "Alipay" / "WeChatPay" / "UnionPay" |

### 复盘数据库格式（可选）

复盘报告数据库属性：

| 属性名 | Notion类型 | 说明 | 示例值 |
|--------|------------|------|--------|
| Name | title | 复盘报告名称 | "2024-01 账单复盘" |
| Period | rich_text | 复盘周期 | "2024-01" |
| Total Income | number | 总收入 | 15000.00 |
| Total Expense | number | 总支出 | 8500.00 |
| Net Balance | number | 净收入 | 6500.00 |
| Transaction Count | number | 交易笔数 | 120 |
| Start Date | date | 起始日期 | "2024-01-01" |
| End Date | date | 结束日期 | "2024-01-31" |
| Summary | rich_text | 汇总信息 | Markdown格式的汇总 |
| Categories | rich_text | 分类统计 | Markdown格式的分类 |

## 内部数据结构

### 标准列名（STANDARD_COLUMNS）

定义在 `parsers/base_parser.py`:

```python
STANDARD_COLUMNS = [
    'transaction_time',    # 交易时间
    'transaction_type',    # 交易分类/类型
    'counterparty',        # 交易对方
    'item_name',           # 商品名称
    'amount',              # 金额
    'income_expense',      # 收/支
    'payment_method',      # 支付方式
    'status',              # 状态
    'transaction_id',      # 交易ID
    'merchant_id',         # 商家ID
    'remark'               # 备注
]
```

### Notion属性格式

```python
{
    'Name': {
        'title': [
            {'text': {'content': '显示名称'}}
        ]
    },
    'Price': {
        'number': 100.50
    },
    'Date': {
        'date': {
            'start': '2024-01-15T10:30:00',
            'time_zone': 'Asia/Shanghai'
        }
    },
    'Category': {
        'select': {'name': '餐饮'}
    },
    'Counterparty': {
        'rich_text': [
            {'text': {'content': '星巴克'}}
        ]
    },
    'Income Expense': {
        'select': {'name': '支出'}
    }
}
```

### 导入结果格式

```python
{
    'success': bool,
    'detected_platform': str,
    'total_records': int,
    'imported': int,
    'updated': int,
    'skipped': int,
    'error': Optional[str]
}
```

### 复盘数据格式

```python
{
    'period': str,  # "2024-01", "2024-Q1", "2024"
    'start_date': str,  # ISO格式日期
    'end_date': str,
    'transaction_count': int,
    'summary': {
        'total_income': float,
        'total_expense': float,
        'net_balance': float,
        'transaction_count': int
    },
    'categories': {
        'category_name': {
            'income': float,
            'expense': float
        }
    }
}
```
