## 代码风格

项目遵循 PEP 8 Python 代码风格指南。

### 基本规则

1. **缩进**: 使用4个空格（不使用制表符）
2. **行长度**: 最大79字符（注释/文档字符串可到72）
3. **空行**: 函数/类定义之间空2行，方法定义之间空1行
4. **编码**: UTF-8
5. **导入**: 每行一个导入，按标准库、第三方、本地分组

### 示例

```python
# Good
def process_bill(file_path: str, platform: str = None) -> dict:
    """Process bill file and return result."""
    if not file_path:
        raise ValueError("file_path is required")

    parser = get_parser(file_path, platform)
    return parser.parse()


# Bad - 缺少类型注解、文档字符串、参数验证
def processBill(fp, p=None):
    prsr = get_parser(fp, p)
    return prsr.parse()
```

## 导入规范

导入语句应按以下顺序组织：

1. 标准库导入
2. 第三方库导入
3. 本地应用导入

每组之间用空行分隔。

### 示例

```python
# 1. 标准库
import os
import logging
from datetime import datetime
from typing import Optional, List, Dict

# 2. 第三方库
import pandas as pd
from fastapi import APIRouter, HTTPException
from sqlalchemy.orm import Session

# 3. 本地导入
from src.config import Config
from src.models import User
from parsers.base_parser import BaseBillParser
```

### 避免

```python
# Bad - 混合顺序、未分组
from fastapi import APIRouter
import os
from src.config import Config
import pandas as pd
```

## 命名规范

### 变量和函数

使用 `snake_case`，描述性命名：

```python
# Good
user_id = 123
file_path = "/path/to/file.csv"
get_user_by_id(user_id: int) -> User
parse_bill_content(content: str) -> dict

# Bad
uid = 123
fp = "/path/to/file.csv"
getUserByID(uid: int)
Parse(x: str)
```

### 类名

使用 `PascalCase`：

```python
# Good
class BillParser:
    class NotionClient:
    class UserUpload:

# Bad
class bill_parser:
class notion_client:
```

### 常量

使用 `UPPER_SNAKE_CASE`：

```python
# Good
MAX_UPLOAD_SIZE = 50 * 1024 * 1024
DEFAULT_TIMEOUT = 30
BCRYPT_ROUNDS = 12

# Bad
max_upload_size = 50 * 1024 * 1024
DefaultTimeout = 30
```

### 私有成员

使用单下划线前缀表示内部使用：

```python
class Parser:
    def _parse_header(self):
        """内部方法，解析头部"""
        pass

    def parse(self):
        """公共方法"""
        self._parse_header()
```

## 错误处理

### 使用特定异常类型

```python
# Good
def get_user(user_id: int) -> User:
    user = db.query(User).filter(User.id == user_id).first()
    if not user:
        raise HTTPException(
            status_code=404,
            detail=f"User {user_id} not found"
        )
    return user

# Bad - 使用通用异常
def get_user(user_id: int) -> User:
    user = db.query(User).filter(User.id == user_id).first()
    if not user:
        raise Exception("User not found")
    return user
```

### 日志记录错误

```python
# Good
def import_bill(file_path: str) -> dict:
    try:
        parser = get_parser(file_path)
        return parser.parse()
    except ValueError as e:
        logger.error(f"Invalid bill format: {e}")
        raise
    except Exception as e:
        logger.error(f"Unexpected error importing bill: {e}", exc_info=True)
        raise

# Bad - 吞掉异常
def import_bill(file_path: str) -> dict:
    try:
        parser = get_parser(file_path)
        return parser.parse()
    except:
        pass  # 永远不要这样做
```

### 提供上下文信息

```python
# Good
raise ValueError(
    f"Invalid platform '{platform}'. "
    f"Supported platforms: {', '.join(SUPPORTED_PLATFORMS)}"
)

# Bad
raise ValueError("Invalid platform")
```

## 日志规范

### 日志级别使用

- **DEBUG**: 详细的诊断信息
- **INFO**: 确认程序按预期运行
- **WARNING**: 意外情况，但程序继续运行
- **ERROR**: 严重错误，程序无法执行某些功能
- **CRITICAL**: 严重错误，程序无法继续

### 日志格式

```python
# Good - 包含上下文
logger.info(f"Parsing bill file: {file_path}")
logger.info(f"Parsed {len(records)} records")
logger.error(f"Failed to connect to Notion: {error}")

# Bad - 缺少上下文
logger.info("Parsing...")
logger.info("Done")
logger.error("Failed")
```

### 敏感信息脱敏

```python
# Good - 脱敏敏感信息
logger.info(f"User {user_id} logged in")
logger.info(f"API key: {api_key[:8]}***")
logger.info(f"Database ID: {db_id[:8]}***")

# Bad - 记录敏感信息
logger.info(f"User password: {password}")
logger.info(f"API key: {api_key}")
logger.info(f"Database ID: {db_id}")
```

## 文档字符串

使用 Google 风格的文档字符串：

```python
def import_bill(
    file_path: str,
    platform: Optional[str] = None,
    user_id: Optional[int] = None
) -> dict:
    """Import bill file to Notion.

    支持单用户模式和多租户模式：
    - 单用户模式：使用全局配置的 Notion API key
    - 多租户模式：根据 user_id 使用用户的 Notion 配置

    Args:
        file_path: 账单文件路径
        platform: 支付平台（alipay, wechat, unionpay），不指定则自动检测
        user_id: 用户ID（多租户模式必需）

    Returns:
        包含导入结果和元数据的字典：
        {
            'success': bool,
            'detected_platform': str,
            'total_records': int,
            'imported': int,
            'updated': int,
            'skipped': int
        }

    Raises:
        ValueError: 当文件格式不支持或配置缺失时
        ConnectionError: 当 Notion API 连接失败时

    Example:
        >>> result = import_bill('/path/to/bill.csv')
        >>> print(result['success'])
        True
    """
    pass
```

class TestBillImport:
    """Bill import tests."""

    def test_import_alipay_bill(self, sample_alipay_file):
        """Test importing Alipay bill file."""
        result = import_bill(sample_alipay_file)
        assert result['success'] is True
