## 账单导入问题

### 问题：无法检测账单格式

**错误信息**:
```
Cannot detect format. Please specify platform explicitly.
```

**原因分析**:
- 文件内容不包含平台特征关键词
- 文件编码不正确
- 文件格式不支持

**排查步骤**:

1. 检查文件格式是否支持
```bash
file /path/to/bill.csv
# 应显示: CSV text, UTF-8 Unicode text
```

2. 检查文件内容关键词
```bash
head -20 /path/to/bill.csv
# 支付宝应包含: "支付宝", "交易时间"
# 微信应包含: "微信支付", "交易时间"
# 银联应包含: "银联", "交易日期"
```

3. 尝试手动指定平台
```bash
python3 main.py --file /path/to/bill.csv --platform alipay
```

**解决方案**:
- 确保从官方渠道下载的原始账单文件
- 使用 `--platform` 参数手动指定平台
- 检查文件是否被修改或损坏

**相关代码**: `parsers/__init__.py:15-80`

---

### 问题：表头行定位失败

**错误信息**:
```
Could not find header line with expected keywords
```

**原因分析**:
- 账单文件格式与预期不符
- 表头行被注释或空行干扰

**排查步骤**:

1. 检查表头位置
```bash
grep -n "交易时间" /path/to/bill.csv
# 找到包含关键字的行号
```

2. 查看文件前几行
```bash
head -30 /path/to/bill.csv | cat -n
# 检查是否有干扰行
```

**解决方案**:
- 手动编辑文件，删除干扰行
- 确保使用官方账单模板
- 联系支持获取帮助

**相关代码**: `parsers/base_parser.py:130-156`

---

### 问题：编码错误

**错误信息**:
```
UnicodeDecodeError: 'gbk' codec can't decode byte...
```

**原因分析**:
- 文件实际编码与检测编码不符
- 文件包含特殊字符

**排查步骤**:

1. 检测文件编码
```bash
file -i /path/to/bill.csv
# 或
chardet /path/to/bill.csv
```

2. 尝试不同编码打开
```python
# 测试脚本
encodings = ['gbk', 'utf-8', 'gb2312', 'latin-1']
for enc in encodings:
    try:
        with open('/path/to/bill.csv', 'r', encoding=enc) as f:
            content = f.read()
        print(f"Success: {enc}")
        break
    except:
        print(f"Failed: {enc}")
```

**解决方案**:
- 系统会自动尝试多种编码
- 如果仍然失败，手动转换编码
- 使用文本编辑器另存为 UTF-8 格式

**相关代码**: `parsers/base_parser.py:56-67`

**错误信息**:

**相关代码**: `src/importer.py:12-105`, `parsers/base_parser.py:226-238`

## Notion连接问题

### 问题：API密钥无效

**错误信息**:
```
Failed to connect to Notion. Please check your API key.
```

**原因分析**:
- API密钥格式错误
- API密钥已过期或被撤销
- 密钥复制不完整

**排查步骤**:

1. 验证密钥格式
```bash
# Notion API Key 应该是 "secret_" 开头的32位以上字符串
echo "your_api_key" | grep -E "^secret_[a-zA-Z0-9]{32,}$"
```

2. 手动测试API
```bash
curl -X GET https://api.notion.com/v1/users/me \
  -H "Authorization: Bearer your_api_key" \
  -H "Notion-Version: 2022-06-28"
```

**解决方案**:
- 重新生成 API 密钥
- 确保完整复制密钥（无多余空格）
- 检查 Notion 集成是否启用

**相关代码**: `src/notion_api.py:240-284`

---

### 问题：数据库访问被拒绝

**错误信息**:
```
无权访问数据库。请检查 API 集成是否已授予该数据库的访问权限
```

**原因分析**:
- 数据库未共享给集成
- 数据库ID错误
- 集成配置不正确

**排查步骤**:

1. 验证数据库ID格式
```python
# 数据库ID应该是32位字符串
import re
db_id = "your_database_id"
if not re.match(r'^[a-zA-Z0-9]{32}$', db_id):
    print("Invalid database ID format")
```

2. 检查数据库权限
   - 在 Notion 中打开数据库
   - 点击右上角 "..." 菜单
   - 确认集成已添加到 "Connections" 列表

**解决方案**:
- 重新复制数据库ID（从数据库URL中获取）
- 在 Notion 中将数据库共享给集成
- 使用验证功能测试连接

**相关代码**: `src/notion_api.py:24-94`

---

### 问题：数据库属性不匹配

**错误信息**:
```
数据库查询失败：Notion 数据库中可能没有 'Date' 属性
```

**原因分析**:
- 数据库缺少必需属性
- 属性名称不匹配
- 属性类型不正确

**排查步骤**:

1. 检查数据库属性
```python
from notion_client import Client
client = Client(auth="your_api_key")
db = client.databases.retrieve("your_db_id")
for prop_name, prop in db["properties"].items():
    print(f"{prop_name}: {prop['type']}")
```

2. 验证必需属性
   - Name (title)
   - Price (number)
   - Date (date)
   - Category (select)
   - Income/Expense (select)

**解决方案**:
- 在 Notion 中添加缺失的属性
- 确保属性名称完全匹配（区分大小写）
- 检查属性类型是否正确

**相关代码**: `src/notion_api.py:128-194`, `src/review_service.py:182-337`

## 认证问题

### 问题：登录失败

**错误信息**:
```
用户名或密码错误
```

**原因分析**:
- 用户名或密码错误
- 账户被锁定
- 账户未激活

**排查步骤**:

1. 检查用户是否存在
```python
from src.services.database import get_db_context
from src.models import User

with get_db_context() as db:
    user = db.query(User).filter(User.username == "username").first()
    if user:
        print(f"User exists, active: {user.is_active}")
        print(f"Locked until: {user.locked_until}")
```

2. 检查账户状态
```bash
# 查看数据库中的用户信息
sqlite3 data/database.sqlite "SELECT username, is_active, locked_until FROM users;"
```

**解决方案**:
- 重置密码
- 等待锁定时间过期（30分钟）
- 联系管理员解锁账户

**相关代码**: `web_service/routes/auth.py`, `src/auth.py:373-423`

## 数据库问题

### 问题：数据库初始化失败

**错误信息**:
```
Failed to initialize database
```

**原因分析**:
- data目录无写入权限
- 数据库文件被锁定
- SQLAlchemy版本不兼容

**排查步骤**:

1. 检查目录权限
```bash
ls -la data/
# 确保目录存在且可写
```

2. 检查数据库文件
```bash
file data/database.sqlite
# 检查文件类型
```

**解决方案**:
- 创建 data 目录
- 检查磁盘空间
- 更新 SQLAlchemy 版本
- 删除损坏的数据库文件重新初始化

**相关代码**: `src/services/database.py:39-53`

**错误信息**:
```
月度复盘数据库未配置。请在设置中配置复盘数据库 ID
```

## 日志调试

### 启用调试日志

在 `.env` 中设置:
```bash
LOG_LEVEL=DEBUG
```

### 查看日志

```bash
# Web服务日志
tail -f web_service/logs/web_service.log

# CLI导入日志
tail -f bill_import.log
```

### 日志级别

- DEBUG: 详细诊断信息
- INFO: 正常运行信息
- WARNING: 警告信息
- ERROR: 错误信息
