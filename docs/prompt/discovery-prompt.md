# Discovery Phase Prompt

**生成时间**: 2026-03-02
**阶段**: Discovery - 需求发现

---

## Prompt 内容

你正在为"账单导入到 Notion"项目进行需求发现。当前项目已支持手动上传支付宝、微信、银联账单文件并自动导入到 Notion 数据库。

### 新功能需求
在现有手动上传账单功能的基础上，新增通过邮箱自动导入账单的功能。系统应能够：
- 连接到用户的邮箱账户
- 自动检测并下载账单邮件附件
- 从邮件内容中提取账单解压密码
- 自动解压并导入账单到 Notion
- 与现有手动上传功能并存

### 你的任务

1. **需求理解与澄清**:
   - 分析这个需求的核心价值和用户场景
   - 识别需要澄清的问题并提出针对性问题
   - 定义功能的边界范围

2. **需求复杂度评估** (v3.0 eval-harness):
   - 功能复杂度: 涉及多少新功能点
   - 技术复杂度: 涉及哪些新技术栈
   - 规模复杂度: 预计影响多少文件/模块
   - 风险复杂度: 有哪些潜在风险

3. **验收标准定义**:
   - 定义功能的验收标准
   - 定义 Capability Evals (功能能力评估)
   - 定义 Regression Evals (回归评估)

4. **风险识别**:
   - 安全风险 (邮箱凭证、邮件内容)
   - 技术风险 (邮件解析、附件下载)
   - 用户体验风险

5. **模板维度分析**:
   - 使用需求分析模板进行全面分析

### 输出要求

生成一份完整的需求发现报告，包含:
- 需求概述
- 澄清问题与建议答案
- 复杂度评估
- 验收标准
- 评估标准 (Capability/Regression Evals)
- 风险分析
- 用户故事

### 上下文信息

项目特点:
- Python + FastAPI Web 服务
- 支持多用户、多租户
- 已有用户认证系统
- 已有账单上传和解析功能
- 已有 Notion API 集成
- 使用 SQLite 数据库
