# Verification Phase Prompt

**生成时间**: 2026-03-02
**阶段**: Verification - 质量验证

---

## Prompt 内容

你正在为"账单导入到 Notion"项目进行质量验证，验证"邮箱账单自动导入"功能的实施质量。

### 前置成果

1. **需求发现报告** (`docs/discovery-report.md`): 验收标准、评估标准
2. **代码库探索报告** (`docs/exploration-report.md`): 架构模式、技术债务
3. **架构设计报告** (`docs/design-report.md`): 设计规范、接口定义
4. **实施代码**: 新增的邮箱功能代码

### 你的任务

执行全面的质量验证，包括：

#### 1. 构建验证
- [ ] 代码编译通过
- [ ] 依赖安装成功
- [ ] 数据库迁移成功

#### 2. 类型检查
- [ ] 使用 mypy 进行类型检查
- [ ] 所有类型注解正确
- [ ] 无类型错误

#### 3. 代码规范
- [ ] PEP 8 风格检查 (flake8)
- [ ] 代码复杂度检查 (mccabe)
- [ ] 安全漏洞扫描 (bandit)

#### 4. 测试验证
- [ ] 单元测试全部通过
- [ ] 测试覆盖率 ≥ 80%
- [ ] 集成测试通过
- [ ] 端到端测试通过

#### 5. 安全验证
- [ ] 凭证加密验证
- [ ] SQL 注入检查
- [ ] XSS 检查
- [ ] 权限控制验证

#### 6. 维度覆盖度验证 (v2.0)
验证需求分析维度和设计分析维度的覆盖度

### 输出要求

生成一份完整的质量验证报告，包含：

1. **验证摘要**
   - 验证通过率
   - 发现的问题数量
   - 风险等级评估

2. **详细验证结果**
   - 每个验证项的结果
   - 失败项的详细说明
   - 修复建议

3. **维度覆盖度报告**
   - 需求维度覆盖度
   - 设计维度覆盖度

4. **问题清单**
   - 高优先级问题
   - 中优先级问题
   - 低优先级问题

5. **修复建议**
   - 每个问题的修复方案
   - 预估修复时间

### 上下文信息

**验证工具**:
- mypy: 类型检查
- flake8: 代码规范
- pytest: 测试框架
- coverage: 覆盖率测试
- bandit: 安全扫描

**质量标准**:
- 测试覆盖率 ≥ 80%
- 代码规范符合 PEP 8
- 无高优先级安全问题
