# 邮件账单导入功能说明

## 功能概述

系统支持从邮箱中自动获取账单邮件并导入到 Notion。您只需配置邮箱账号，系统会自动：

1. 连接到配置的邮箱账号
2. 识别来自支付平台的账单邮件
3. 下载账单附件文件
4. 自动导入账单到 Notion

**支持的支付平台**：
- 支付宝 (Alipay)
- 微信支付 (WeChat Pay)
- 银联 (UnionPay)

---

## 邮件格式要求

### 1. 发件人要求

系统只处理来自以下官方邮箱地址的账单邮件：

| 支付平台 | 官方发件人邮箱 |
|----------|---------------|
| **支付宝** | `alipay@alipay.com`<br>`service@alipay.com`<br>`notify@alipay.com` |
| **微信支付** | `weixinpay@wechat.com`<br>`pay@wechat.com`<br>`tenpay@wechat.com` |
| **银联** | `unionpay@95516.com`<br>`service@95516.com`<br>`payment@95516.com` |

**重要**：只有来自以上官方邮箱的邮件才会被识别为账单邮件。来自其他发件人的邮件将被忽略。

### 2. 附件格式要求

系统只处理以下格式的附件文件：

| 文件格式 | 扩展名 | 说明 |
|----------|--------|------|
| **CSV 文件** | `.csv` | 推荐格式，直接可解析 |
| **ZIP 压缩包** | `.zip` | 支持密码保护的压缩包 |

**支持的 ZIP 文件**：
- 可以是密码保护的 ZIP 文件
- 系统会自动从邮件正文中提取解压密码
- 支持 CSV 密码格式：`密码: xxxxx`、`解压密码: xxxxx`、`password: xxxxx`

**不支持的格式**：
- `.xls` / `.xlsx` (Excel 文件)
- `.pdf` (PDF 文件)
- `.rar` / `.7z` (其他压缩格式)
- 其他文件类型

### 3. 邮件主题要求

系统不限制邮件主题，任何来自官方邮箱的邮件都会被检查。但通常账单邮件的主题类似：

- 支付宝：`支付宝账单`、`支付宝交易明细` 等
- 微信支付：`微信支付账单`、`微信账单` 等
- 银联：`银联账单`、`银联交易明细` 等

### 4. 邮件正文要求（ZIP 文件）

如果账单文件是 ZIP 压缩包，系统会尝试从邮件正文中提取解压密码。

**支持的密码格式**：

```
密码: abc123
解压密码: abc123
password: abc123
提取码: abc123
验证码: abc123
```

**密码提取规则**：
- 密码长度：4-20 个字符
- 字符类型：字母和数字
- 不区分大小写
- 自动识别中英文格式

**示例邮件正文**：

```
尊敬的用户：

您的账单文件已生成，请查收附件。

文件密码：Alipay2024

如有疑问，请联系客服。
```

### 5. 账单文件格式要求

下载后的账单文件（CSV 或 ZIP 解压后的 CSV）需要符合以下格式：

#### 文件编码

- **推荐**：GBK 编码（中文账单常用）
- **支持**：UTF-8 编码
- 系统会自动检测编码

#### CSV 格式

标准的 CSV 格式，包含表头行和数据行。

**示例（支付宝）**：

```csv
交易号,商家订单号,交易创建时间,付款时间,商品名称,金额(元),交易状态
2024030222001,20240302001,2024-03-02 12:30:45,2024-03-02 12:31:20,购物消费,99.00,交易成功
```

**示例（微信支付）**：

```csv
交易时间,交易类型,交易对方,商品说明,金额(元),收/支,交易状态
2024-03-02 12:30:45,微信红包,张三,转账,50.00,支出/已退款,已退款
```

**示例（银联）**：

```csv
交易日期,交易时间,交易类型,商户名称,交易金额(元),账户余额(元)
2024-03-02,12:30:45,消费,XX超市,128.50,5000.00
```

## 使用流程

### 步骤 1: 配置邮箱

1. 登录系统
2. 进入"设置" → "邮箱配置"
3. 点击"添加邮箱配置"
4. 填写邮箱信息：
   - 选择邮箱服务商（QQ/163/Gmail/Outlook/自定义）
   - 输入邮箱地址
   - 输入密码/授权码（注意：不是登录密码，是授权码）
   - 确认 IMAP 服务器和端口
5. 点击"测试连接"验证配置
6. 保存配置

**获取授权码**：
- **QQ 邮箱**：设置 → 账户 → POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务 → 生成授权码
- **163 邮箱**：设置 → POP3/SMTP/IMAP → 客户端授权密码 → 新增授权码
- **Gmail**：Google 账户 → 安全性 → 两步验证 → 应用专用密码
- **Outlook**：通常使用登录密码即可

### 步骤 2: 触发账单导入

配置邮箱后，有两种导入方式：

#### 方式 1: 手动导入（推荐）

1. 进入"设置" → "邮箱配置"
2. 找到已配置的邮箱
3. 点击"立即检查邮箱"按钮
4. 系统会：
   - 连接到邮箱
   - 获取最近的 50 封邮件
   - 识别账单邮件
   - 下载账单附件
   - 导入到 Notion
5. 查看导入结果

#### 方式 2: 自动导入

系统会按照设置的检查频率自动检查邮箱：
- **每小时**：每小时自动检查一次
- **每天**：每天凌晨 2 点检查一次
- **每周**：每周日凌晨 2 点检查一次

### 步骤 3: 查看导入历史

1. 进入"账单历史"页面
2. 查看最近的导入记录
3. 每条记录显示：
   - 导入时间
   - 导入来源（邮箱）
   - 导入状态（成功/失败）
   - 导入记录数

## 常见问题

### Q1: 为什么我的账单邮件没有被识别？

**可能原因**：
1. 发件人邮箱不在白名单中
   - 确认邮件来自支付平台的官方邮箱
   - 检查发件人邮箱地址是否匹配

2. 邮件没有附件
   - 确认邮件包含 CSV 或 ZIP 附件
   - 检查附件是否被邮件客户端过滤

3. 附件格式不支持
   - 确认附件是 `.csv` 或 `.zip` 格式
   - 不支持 Excel、PDF 等格式

### Q2: ZIP 文件解压失败怎么办？

**可能原因**：
1. 密码提取失败
   - 确认邮件正文包含密码信息
   - 确认密码格式符合要求

2. ZIP 文件损坏
   - 重新从支付平台下载账单
   - 确认 ZIP 文件可以正常打开

### Q3: 为什么导入的记录数不对？

**可能原因**：
1. 账单文件格式不正确
   - 检查 CSV 文件是否有表头
   - 确认列名称正确

2. 编码问题
   - 系统会自动检测编码
   - 如果失败，尝试用记事本另存为 UTF-8 编码

3. 过滤规则
   - 系统会过滤"不计收支"的记录
   - 这是正常的，不影响账单准确性

### Q4: 如何获取账单文件？

**支付宝**：
1. 打开支付宝 APP
2. 进入"我的" → "账单"
3. 点击右上角"..."
4. 选择"开具账单"或"导出账单"
5. 选择时间范围和格式
6. 发送到邮箱

**微信支付**：
1. 打开微信 APP
2. 进入"我" → "服务" → "钱包" → "账单"
3. 点击右上角"..."
4. 选择"账单下载"
5. 选择时间范围和格式
6. 发送到邮箱

**银联**：
1. 登录银联官网或 APP
2. 进入"我的账户" → "交易明细"
3. 选择时间范围
4. 点击"导出"或"下载"
5. 发送到邮箱

### Q5: 系统会重复导入同一封邮件吗？

**不会**。系统会记录已处理的邮件：
- 每封邮件只会被处理一次
- 邮件 UID（唯一标识符）会保存到数据库
- 重复的邮件会被自动跳过

### Q6: 支持多个邮箱配置吗？

**支持**。您可以：
- 配置多个不同的邮箱账号
- 每个邮箱独立配置
- 系统会从所有已配置的邮箱获取账单

例如：
- QQ 邮箱：接收支付宝账单
- 163 邮箱：接收微信账单
- Gmail：接收银联账单

### Q7: 如何修改邮箱检查频率？

1. 进入"设置" → "邮箱配置"
2. 找到要修改的邮箱配置
3. 点击"编辑"按钮
4. 修改"检查频率"：
   - 每小时
   - 每天
   - 每周
5. 保存配置

## 安全说明

### 密码加密

- 邮箱密码/授权码使用 AES-256 加密存储
- 加密密钥使用 PBKDF2 派生，100,000 次迭代
- 符合安全最佳实践

### IMAP 连接

- 使用 SSL/TLS 加密连接
- 默认端口 993（IMAPS）
- 不会在日志中显示密码

### 数据隔离

- 每个用户的邮箱配置独立
- 用户只能访问自己的配置
- 数据库级别的隔离保护

## 技术说明

### RFC 2971 - IMAP ID 扩展

系统实现了 IMAP ID 扩展（RFC 2971），用于客户端标识：

```python
{
    "name": "NotionBillImporter",
    "version": "2.2.0",
    "vendor": "CustomClient",
    "support-email": "noreply@notionbillimporter.local",
    "os": "Python",
    "os-version": "3.8.10"
}
```

这对于某些邮件服务商（如 163 邮箱）是必需的。

### 邮件处理流程

```
1. 连接到 IMAP 服务器
   ↓
2. 发送 IMAP ID（RFC 2971）
   ↓
3. 登录邮箱
   ↓
4. 获取最近的 50 封邮件
   ↓
5. 对每封邮件：
   - 检查是否已处理
   - 识别发件人是否在白名单
   - 提取附件（CSV/ZIP）
   - 如果是 ZIP，提取密码并解压
   ↓
6. 解析账单文件
   ↓
7. 导入到 Notion
   ↓
8. 记录已处理的邮件
```

### 错误处理

- 连接失败：记录错误日志，不影响其他邮箱
- 附件下载失败：跳过该附件，继续处理其他
- 解析失败：记录详细错误信息
- Notion 导入失败：记录失败记录，不影响其他记录
